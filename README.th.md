## จุดเด่น

- **ดูโควต้าสด** – ช่วง 5 ชั่วโมงและรายสัปดาห์ของทุกผู้ให้บริการ บนเมนูบาร์
- **คลิกเดียวเห็นรายละเอียด** – เหลือน้อยสุด เวลารีเซ็ต โทเค็น และค่าใช้จ่าย
- **เตือนอัจฉริยะ** – เตือนเมื่อใกล้หมด และแนะนำให้สลับไปใช้ตัวที่ยังเหลือ
- **กราฟแนวโน้ม** – กิจกรรมรายวัน และค่าใช้จ่าย 7 / 30 / 90 วัน
- **เป็นส่วนตัว** – อ่านข้อมูลในเครื่องเท่านั้น ไม่แตะรหัสผ่าน ไม่ใช้เน็ต

## วิธีติดตั้ง

1. [ดาวน์โหลดไฟล์ `.dmg` ล่าสุด](https://github.com/PerthTheIamCat/ai-usage-bar/releases/latest)
2. เปิดไฟล์ แล้วลาก **AIUsageBar** ไปไว้ใน **Applications**
3. ครั้งแรก **กด Control ค้างแล้วคลิก → Open** (แอปเซ็นแบบ ad-hoc)

จากนั้นคลิกไอคอนบนเมนูบาร์ ถ้าใช้ Claude Code ให้กด **Set Up Status Line Bridge** ใน popover หนึ่งครั้ง
