## ✨ จุดเด่น

| | |
|---|---|
| 📊 **โควต้าสด** | ช่วง 5 ชั่วโมงและรายสัปดาห์ของทุกผู้ให้บริการ บนเมนูบาร์ |
| 🎯 **เหลือน้อยสุด** | วงแหวนเดียวบอกว่าตอนนี้เหลือเท่าไร |
| ⚠️ **เตือนอัจฉริยะ** | เตือนเมื่อใกล้หมด และแนะนำให้สลับไปใช้ตัวที่ยังเหลือ |
| 📈 **แนวโน้ม** | กิจกรรมรายวัน และกราฟค่าใช้จ่าย 7 / 30 / 90 วัน |
| 👥 **หลายบัญชี** | ติดตามบัญชี Claude Code และ Codex เพิ่มเติมได้ |
| 🔒 **เป็นส่วนตัว** | อ่านไฟล์ในเครื่องเท่านั้น ไม่แตะรหัสผ่าน ไม่เรียกเน็ต |

## 🚀 วิธีติดตั้ง

| ขั้นที่ | |
|:---:|---|
| **1** | [**ดาวน์โหลดไฟล์ `.dmg` ล่าสุด**](https://github.com/PerthTheIamCat/ai-usage-bar/releases/latest) |
| **2** | เปิดไฟล์ แล้วลาก **AIUsageBar** ไปไว้ใน **Applications** |
| **3** | เปิดครั้งแรก: กด **Control ค้างแล้วคลิก → Open** (แอปเซ็นแบบ ad-hoc) |
| **4** | คลิกไอคอนบนเมนูบาร์ ถ้าใช้ Claude Code ให้กด **Set Up Status Line Bridge** หนึ่งครั้ง |

> ตั้งแต่เวอร์ชัน 0.2.0 แอปอัปเดตตัวเองอัตโนมัติ

<br>

## 🔌 ผู้ให้บริการที่รองรับ

| ผู้ให้บริการ | การใช้งานวันนี้ | โควต้า |
|---|---|---|
| **Claude** | log session ของ Claude Code | Status-line bridge หรือ Claude Desktop |
| **Codex** | log session ของ Codex | `rate_limits` ของ Codex |
| **Antigravity** | ประวัติ CLI และฐานข้อมูล IDE | snapshot status-line ของ CLI |
